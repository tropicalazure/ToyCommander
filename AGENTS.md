# ToyCommander -- agent guide

PWA for local and partner-remote control of Bluetooth intimate devices (patterns, audio-reactive mode, shareable remote sessions). See `README.md` and `PROJECT_STRUCTURE.md`.

Follow `~/Projects/AGENTS.md` (home lab rules) first. Never print or commit secrets (`.env*`, keystores, service-account JSON).
